### **Объяснение лабораторной работы и работы программы**

---

#### **Цель работы**
1. **Захват видео с камеры**: Получить поток данных с веб-камеры в реальном времени.
2. **Обработка кадров**: Применить фильтр Гауссова размытия к каждому кадру.
3. **Сохранение результата**: Записать обработанное видео в файл формата AVI.

---

#### **Ключевые компоненты программы**

1. **Захват видео (`cv::VideoCapture`)**  
   - Класс `cv::VideoCapture` открывает подключение к камере (индекс `0` — первая доступная камера).
   - Метод `cap.isOpened()` проверяет, удалось ли подключиться к камере.

2. **Обработка кадров (`cv::GaussianBlur`)**  
   - Фильтр Гаусса сглаживает изображение, уменьшая шумы.  
   - Параметры:  
     - `cv::Size(15, 15)` — размер ядра фильтра.  
     - `0` — стандартное отклонение (автовычисление).

3. **Запись видео (`cv::VideoWriter`)**  
   - Класс `cv::VideoWriter` создаёт файл для записи.  
   - Параметры:  
     - `fourcc('M','J','P','G')` — кодек MJPG.  
     - `fps` — частота кадров.  
     - `cv::Size(width, height)` — разрешение видео.

4. **Отображение результата (`cv::imshow`)**  
   - Окно `Webcam` отображает обработанные кадры в реальном времени.

---

#### **Как это работает**
1. **Инициализация камеры**  
   ```cpp
   cv::VideoCapture cap(0);
   ```
   - Открывает камеру с индексом `0`.

2. **Получение параметров видео**  
   ```cpp
   int width = cap.get(cv::CAP_PROP_FRAME_WIDTH);
   int height = cap.get(cv::CAP_PROP_FRAME_HEIGHT);
   ```
   - Определяет разрешение кадра.

3. **Создание файла для записи**  
   ```cpp
   cv::VideoWriter writer("output.avi", cv::VideoWriter::fourcc('M','J','P','G'), fps, cv::Size(width, height));
   ```
   - Настраивает кодек, FPS и разрешение.

4. **Основной цикл обработки**  
   ```cpp
   while (true) {
       cap >> frame; // Захват кадра
       cv::GaussianBlur(frame, blurred_frame, cv::Size(15, 15), 0); // Размытие
       writer.write(blurred_frame); // Запись кадра
       cv::imshow("Webcam", blurred_frame); // Отображение
   }
   ```
   - Каждый кадр обрабатывается и сохраняется.

5. **Завершение работы**  
   ```cpp
   cap.release();
   writer.release();
   ```
   - Освобождает ресурсы камеры и файла.

---

#### **Инструкция по выполнению задания**
1. **Установите зависимости**:
   ```bash
   sudo pacman -S opencv gcc cmake
   ```

2. **Соберите проект через CMake**:
   ```bash
   mkdir build && cd build
   cmake .. && make
   ```

3. **Запустите программу**:
   ```bash
   ./video_capture
   ```

4. **Результаты**:
   - Видео с камеры отображается в окне `Webcam`.
   - Обработанные кадры сохраняются в файл `output.avi`.

   Используйте метод `cv::matchTemplate()` для сравнения кадра с шаблоном.

2. **Другие фильтры**

   - Конвертация в градации серого: `cv::cvtColor(frame, gray_frame, cv::COLOR_BGR2GRAY)`.

---

#### **Почему это важно?**
- **OpenCV** — стандартный инструмент для задач компьютерного зрения.  
- **Фильтрация** — базовый этап обработки изображений (удаление шумов, подготовка данных).  
- **Запись видео** — полезно для анализа данных оффлайн (например, в системах видеонаблюдения).

#### **Ответы на вопросы из методички:**
- **Почему важно освобождать ресурсы (release())?**
	Для предотвращения утечек памяти и корректного завершения работы с устройствами (камера, файлы).

- **Как выбрать кодек для записи?**
	В Linux поддерживаются кодеки, установленные в системе (например, MJPG, XVID). Проверьте доступные через ffmpeg -codecs.

- **Как добавить другие фильтры?**
	Используйте функции OpenCV: cv::Canny() для детекции границ, cv::cvtColor() для конвертации цветового пространства.
