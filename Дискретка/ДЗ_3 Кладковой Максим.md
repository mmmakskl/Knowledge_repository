**1. Доказать формулу**
> **2)** `s(0) * x = x`

**Правила:**
```
C(x):    x * 0      = 0  
D(x,y):  x * s(y)   = (x * y) + x  
B(x,y):  x + s(y)   = s(x + y)  
A(x):    x + 0      = x  
```
---
### 1.1. База индукции (x = 0)
**Формула:** `s(0) * 0 = 0`
1. Применяем правило C(x) к `s(0) * 0`, подстановка `x ← s(0)`:
    ```
    C(x): x * 0 = 0
    s(0) * 0  =[C:x/s(0)]⇒ 0
    ~~~~~~~~~      ~
    ```
2. Правая часть исходной формулы при x=0 — это просто `0`.  
    ⇒ **база доказана.**
---
### 1.2. Индукционный шаг (x → s(y))
**ИП:** `s(0) * y = y`  
**Цель:** `s(0) * s(y) = s(y)`
1. Применяем правило D(x,y) к `s(0) * s(y)`, подстановка `x ← s(0)`, `y ← y`:
    ```
    D(x,y): x * s(y) = (x*y) + x
    s(0) * s(y)  =[D:x/s(0),y/y]⇒ (s(0)*y) + s(0)
    ~~~~~~~~~~~                      ~~~~~~~~
    ```
2. По ИП (`s(0)*y = y`):
    ```
    (s(0)*y) + s(0)  =[ИП]⇒ y + s(0)
    ~~~~~~~~~~~~~~~       ~~~~~~~~
    ```
3. Применяем B(x,y) к `y + s(0)`, подстановка `x ← y`, `y ← 0`:
    ```
    B(x,y): x + s(y) = s(x + y)
    y + s(0)  =[B:x/y,y/0]⇒ s(y + 0)
    ~~~~~~~         ~~~~~~~~
    ```
4. Применяем A(x) к `y + 0`, подстановка `x ← y`:
    ```
    A(x): x + 0 = x
    y + 0  =[A:x/y]⇒ y
    ~~~~       ~
    ```
    ⇒ `s(y + 0) = s(y)`.
Таким образом
```
s(0) * s(y) = s(y).
```
⇒ **индукционный шаг доказан**, по индукции формула `s(0)*x = x` доказана.

**2. Доказать формулу**

> **5)** `x * d(y) = d(x * y)`

**Правила:**
```
C(x):    x * 0      = 0  
D(x,y):  x * s(y)   = (x * y) + x  
E:       d(0)       = 0  
F(x):    d(s(x))    = s(s(d(x)))  
```
При выводе понадобилась лемма **L1**.

---
### 2.1. Лемма L1(a,b)
> **L1(a,b):** `(d(a) + b) + b = d(a + b)`
#### База (b = 0)
1. Левая часть:
    ```
    (d(a) + 0) + 0  
      A(x): x + 0 = x
    ⇒ d(a) + 0  =[A:x/d(a)]⇒ d(a)
    ~~~~~~~~~      ~~~~~~
    ```
2. Правая часть:
    ```
    d(a + 0)  
      A(x): x + 0 = x
    ⇒ a + 0  =[A:x/a]⇒ a
      ~~~~       ~
    ⇒ d(a+0)=d(a)
    ```

⇒ база L1 доказана.

#### Индукционный шаг (b → s(b))

ИПₗ: `(d(a)+b)+b = d(a+b)`  
Цель: `(d(a)+s(b)) + s(b) = d(a + s(b))`
1. 
```
d(a) + s(b)  
  B(x,y): x + s(y) = s(x + y)
=[B:x/d(a),y/b]⇒ s(d(a) + b)
 ~~~~~~~~~~~~~~    ~~~~~~~~
```
    
2. 
```
s(d(a) + b) + s(b)  
  B(x,y)
=[B:x/s(d(a)+b),y/b]⇒ s(s((d(a)+b) + b))
 ~~~~~~~~~~~~~~~~~~~~~    ~~~~~~~~~~~~~
```
    
3. По ИПₗ: `(d(a)+b)+b = d(a+b)`
    ```
    s(s((d(a)+b)+b))  =[ИП_L1]⇒ s(s(d(a+b)))
    ~~~~~~~~~~~~~~~~~~~~         ~~~~~~~~~~~~~
    ```
4. 
```
s(s(d(a+b)))  
	F(x): d(s(x)) = s(s(d(x)))
←– обратная унификация x/(a+b)
⇒ d(s(a+b))
~~~~~~~~~~~~
```
5. Но по B(x,y): `s(a+b) = a + s(b)` ⇒ `d(s(a+b)) = d(a + s(b))`.  
    ⇒ лемма L1 доказана.
---
### 2.2. Доказательство основной формулы
#### База (y = 0)
```
x * d(0)  
  E: d(0)=0
⇒ x * 0  
  C(x)
⇒ 0
```
Правая часть: `d(x * 0) = d(0) = 0`.  
⇒ база доказана.
#### Индукционный шаг (y → s(y))
ИП: `x * d(y) = d(x * y)`  
Цель: `x * d(s(y)) = d(x * s(y))`
1. Левая часть:
    ```
    x * d(s(y))  
      F: d(s(y))=s(s(d(y)))
    ⇒ x * s(s(d(y)))  
    ```
    затем дважды D:
    ```
    x * s(s(d(y)))  
    =[D:x/x,y/s(d(y))]⇒ (x * s(d(y))) + x  
                           ~~~~~~~~~~~~
    =[D:x/x,y/d(y)]  ⇒ (x * d(y)) + x + x
    ~~~~~~~~~~~~~~           ~~~~~  
    ```
    по ИП: `x*d(y)=d(x*y)`
    ```
    ⇒ (d(x*y) + x) + x
    ```
2. Правая часть:
    ```
    x * s(y)  
    =[D]⇒ (x*y) + x  
    ⇒ d((x*y)+x)
    ```
3. Сравниваем:
    ```
    (d(x*y) + x) + x  =?=  d((x*y) + x)
    ```
    это  **L1**  с `a = x*y`, `b = x`.  
    ⇒ по L1: равенство выполняется.
По индукции формула `x * d(y) = d(x*y)` доказана.
