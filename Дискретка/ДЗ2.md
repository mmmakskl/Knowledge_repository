Задачи на составление схем нормальных алгоритмов
Маркова и выполнения вычислений.

Выберите один вариант или составьте аналогичную задачу.

1. Составьте схему нормального алгортма Маркова
для выписывания слова в алфавите {a,b} в обратном порядке.
Например, для слова "abaa" результатом будет "aaba".
Приведите протокол вычислений для слова "bbab".

2. Составьте схему нормального алгортма Маркова
для сортировки символов в слове алфавита {a,b,c}.
Например, для слова "bacbabc" должно получиться слово "aabbbcc".
Приведите протокол вычислений для слова "abcbab".

3. Составьте схему нормального алгортма Маркова
для определения, каких символов "a" или "b" больше
в слове в алфавите {a,b} в виде слова из избыточных
символов большего количества.
Например, для слова "abaabaab" результатом будет слово "aa",
так как в слове 5 символов "а" и 3 символа "b" и избыток
"a" над "b" будет 2. В случае одинакового числа символов
"a" и "b" резульатом будет пустое слово.
Например, результатом для слова "babbaa" будет пустым.
Приведите протокол вычислений для слова "abaabaab".

4. Составьте схему нормального алгортма Маркова
для вычисления остатка от деления одного натурального числа
на другое. Числа задаются унарным кодом из символа "|".
Делитель отделяется от делителя символом "%".
Результат должет также быть представлен в виде числа в унарном коде
из символа "|".
Например, для вычисления остатка от деления 8 на 3 исходным
данным будет слово "||||||||%|||" и результатом будет слово "||",
обозначающее число 2.
Приведите протокол вычисления для слова "|||||||%||".

5. Составьте схему нормального алгортма Маркова
для вычисления целой части частного от деления одного натурального числа
на другое. Числа задаются унарным кодом из символа "|".
Делитель отделяется от делителя символом "/".
Результат должет также быть представлен в виде числа в унарном коде
из символа "|".
Например, для вычисления целой части частного от деления 7 на 3 исходным
данным будет слово "|||||||/|||" и результатом будет слово "||",
обозначающее число 2.
Приведите протокол вычисления для слова "|||||||/||".

6. Составьте схему нормального алгортма Маркова
для сложения двух натуральных чисел в двоичном позиционным коде
в алфавите из символов "0" и "1", записанных старшими разрядами влево.
Между слагаемыми в исходном слове стоит символ "+".
Результат тоже должен быть словом, представляющим число в таком же
двоичном коде.
Например, для вычисления суммы 6 и 4 исходное слово будет "110+100".
Результатом будет слово "1010", обозначающее число 10.
Приведите протокол вычисления для слова "101+11".

7. Составьте схему нормального алгортма Маркова
для сравнения двух натуральных чисел в двоичном позиционным коде
в алфавите из символов "0" и "1", записанных старшими разрядами влево.
Результатом будет слово "A", если первое число строго больше второго,
слово "L", если первое число строго меньше второрго и символ "E",
если числа равны. Слова разделяются символом "?".
Первое слово пишется левее символа "?", второе - правее.
Пример: для слова "110?101" результат будет "A", так как 6 > 5.
Приведите протокол вычисления для слова "101?11".

8. Составьте схему нормального алгортма Маркова
для подсчета числа вхождений левой строки в правую в алфавите {a,b}.
Строки разделяются символом "?".
Результат представьте в унарном коде из символа "|".
Например, для слова "abaa?bbabaabaabaaa" результатом будет слово "||",
так как слово "abaa" входит м в слово "bbabaabaabaaa" 2 раза.
Приведите протокол вычилений для слова "aba?aababa".
