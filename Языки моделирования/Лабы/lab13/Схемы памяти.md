## Общая информация
### Пример функциональной классификации запоминающего устройства
ROM - Read-Only Memory (ЗУ только для чтения или запоминающее устройство,  ПЗУ)
PROM - Programmable ROM (программируемое ПЗУ, ППЗУ)
EEPROM - Electrically Erasable PROM (электрически-стираемое программируемое ПЗУ)
RAM Random Access Memory
SRAM Static RAM
DRAM Dynamic RAM
CACHE Memory
ПЗУ - постоянное ЗУ
ППЗУ - полупостоянное или программируемое постоянное ЗУ
РПЗУ - репрограммируемое ЗУ
ОЗУ - оперативное ЗУ
ПВ - произвольная выборка. Если иначе, то последовательные запись и считывание
АЗУ - ассоциативные ЗУ. В АЗУ поиск ячейки ЗУ ведется не по адресам а по специальному признаку, для которого в начале слова отводится несколько разрядов.
МФЗУ - многофункционаольное ЗУ. Под многофункциональностью понимают логическую обработку информации перед запоминанием.

## Пункт 1,2: простейшая память емкостью 4 бита : gdf, vhd 
**Входы**: A0; A1; D; C
**Выход:** Q
![[Pasted image 20241206200952.png]]
**Адресные входы (A0,A1)** выбирают одну из 4 ячеек памяти.
**Сигнал записи (C)** разрешает запись данных (DD) в выбранную ячейку.
**Выход (Q)** отображает содержимое выбранной ячейки, независимо от CC.

Если C=′1′ (сигнал записи активен) и на входе D есть данные, то они записываются в выбранную ячейку памяти. Какая именно ячейка будет выбрана, определяется адресными входами A0 и A1. Например:
- A0A1=00: записываем данные в ячейку 0.
После записи данных в ячейку:
- Выход Q всегда показывает содержимое выбранной ячейки, независимо от сигналов D и C.
- Если позже мы обращаемся к ячейке с адресом A0A1=00, то на выходе Q появится значение, которое ранее было записано в эту ячейку. 
### **Функциональная таблица**:

| A1  | A0  | Операция          | Сигнал C | D   | Q            |
| --- | --- | ----------------- | -------- | --- | ------------ |
| 0   | 0   | Чтение ячейки 0   | 0        | -   | Содержимое 0 |
| 0   | 0   | Запись в ячейку 0 | 1        | D   | Содержимое 0 |
| 0   | 1   | Чтение ячейки 1   | 0        | -   | Содержимое 1 |
| 0   | 1   | Запись в ячейку 1 | 1        | D   | Содержимое 1 |
| 1   | 0   | Чтение ячейки 2   | 0        | -   | Содержимое 2 |
| 1   | 0   | Запись в ячейку 2 | 1        | D   | Содержимое 2 |
| 1   | 1   | Чтение ячейки 3   | 0        | -   | Содержимое 3 |
| 1   | 1   | Запись в ячейку 3 | 1        | D   | Содержимое 3 |

## Пункт 3: Память емкостью 4-е 8 битных слова
**Входы:** WR, RD, A1, A0, D1\[0..7], D2\[0..7\], D3\[0..7], D4\[0..7]
**Выходы:** Q1\[7..0], Q2\[7..0], Q3\[7..0], Q4\[7..0]
### **Описание входов:**

- **WR** (Write): Сигнал записи, активирует процесс записи данных в память.
- **RD** (Read): Сигнал чтения, активирует процесс считывания данных из памяти.
- **A1, A0**: Адресные входы, указывают, какая из 4 ячеек (0–3) используется для записи или чтения.
- **D1\[0..7],D2\[0..7],D3\[0..7],D4\[0..7]**: Входы данных, по одному 8-битному слову для каждой ячейки памяти.

### **Описание выходов:**

- **Q1\[7..0],Q2\[7..0],Q3\[7..0],Q4\[7..0] Выходы данных, отображающие содержимое ячеек памяти.
### **Принцип работы:**

1. **Выбор ячейки:**  
    Адресные входы A1A1 и A0A0 определяют, с какой из 4 ячеек памяти будет производиться операция.
    
    - A1A0=00: Выбрана ячейка 1.
    - A1A0=01: Выбрана ячейка 2.
    - A1A0=10: Выбрана ячейка 3.
    - A1A0=11: Выбрана ячейка 4.
2. **Запись данных (WR=1):**  
    - Данные из входов D1, D2, D3, или D4 записываются в выбранную ячейку памяти.
    - Например, если A1A0=10, то данные из D3\[0..7] записываются в третью ячейку памяти.
3. **Чтение данных (RD=1):**
    - Содержимое выбранной ячейки памяти отправляется на соответствующий выход Q1, Q2, Q3, или Q4.
    - Например, если A1A0=01, то данные из второй ячейки памяти отображаются на выходе Q2\[7..0]Q2\[7..0].
4. **Поведение при неактивных WR и RD:**
    - Если WR и RD не активны (WR=0,RD=0), память выключена.
### **Особенности:**
- Одновременно может выполняться либо запись, либо чтение (но не обе операции сразу).
- Память поддерживает 4 отдельные 8-битные слова, которые могут быть независимо адресованы, записаны и считаны.
