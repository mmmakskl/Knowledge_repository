# №1 Конечно-разностный метод для решения краевых задач ОДУ. Использование метода прогонки при его реализации
Метод стрельбы - сведение краевой задачи к многократному решению задачи Коши
Конечно-разностные методы - сведение краевой задачи к решению системы линейных уравнений.
$\frac{d^2y}{dt^2} + p(t)\frac{dy}{dt} + q(t)y(t) = f(t)$, $t\in[a,b]$
$\alpha_1y(a)+\beta_1\frac{dy(a)}{dt}=\gamma_1$ ,  $\alpha_2y(b)+\beta_2\frac{dy(b)}{dt}=\gamma_2$ 
Введем дискретные значения независимых переменных:
$t_k = t_0 + kh$, $h = \frac{b-a}{N}$, $t_0 = a$, $t_N = b$, $y_k = y(t_k)$
Исходное уравнение запишем в данных точках, предварительно аппроксимировав первою и вторую производную по формулам численного дифференцирования:
$\frac{dy(t_k)}{dt}\approx\frac{y_{k+1}-y_{k_1}}{2h}$,   $\frac{d^2y(t)}{dt^2}\approx\frac{y_{k+1}-2y_k+y_{k-1}}{h^2}$ 
Получаем систему линейных алгебраических уравнений относительно $y_k$:
==(1)== $a_ky_{k-1}+b_ky_k+c_ky_{k+1} = -h^2f_k$,   k = 1,2,...N_1; где $a_k = \frac{hp_k}{2}-1$, $b_k = 2-h^2q_k$, $c_k = -\frac{hp_k}{2}-1$
Тогда граничные условия: 
==(2)== $\alpha_1y_0+\beta_1\frac{-y_2 + 4y_1 - 3y_0}{2h} = \gamma_1$;  $\alpha_2y_N+\beta_2\frac{3y_N - 4y_{N-1} + y_{N-2}}{2h} = \gamma_2$; (использованы формулы численного дифференцирования для дифференцирования в начале и в конце таблицы)
Выразим значения $y_0$ и $y_N$ из (2) и подставим в первое и последнее уравнения системы (1). Приведем подобные слагаемые -> каждое уравнение будет иметь только 2 неизвестные:

Уравнения (1) для k = 2,3,...N-2 совместно с (3) порождают линейную систему с трехдиагональной матрицей:
![[Pasted image 20250320233810.png]]
#### Метод прогонки
Модификация метода Гаусса, применительно к таким системам - ==метод перегонки== Получим расчетные формулы метода
Решение системы найдем в виде:
==(4)== $y_k = \Theta_k y_{k+1} + \Psi_k$;    k = 1,2,...,N-2
Выразим $y_{k-1}$ и  $y_{k+1}$ 
==(5)== $y_{k-1} = \Theta_{k-1}y_k + \Psi_{k-1} = \Theta_{k-1}\Theta_ky_{k+1} + (\Theta_{k-1}\Psi_k+\Psi_{k-1})$
Подставим (4) и (5) в (1)
 $[\Theta_k(a_k\Theta_{k-1} + b_k)+c_k]y_{k+1} + [\Psi_k(a_k\Theta_{k-1}+b_k)+a_k\Psi_{k-1}+h^2f_k] = 0$ 
 Приравняв каждую квадратную скобку к нулю, получаем уравнения для получения $\Theta_k$ и $\Psi_k$
 ==(6)== $\Theta_k = -\frac{c_k}{b_k+a_k\Theta_{k-1}}$; $\Psi_k = -\frac{a_k\Psi_{k-1} + h^2f_k}{b_k+a_k\Theta_{k-1}}$; - нахождение данных коэффициентов - прямая прогонка
  $\Theta_1 = - \frac{\tilde{c_1}}{\tilde{b_1}}$ ; $\Psi_1 = - \frac{h^2\tilde{f_1}}{\tilde{b_1}}$ - получаются сравнением (4) с первым уравнением (3)
  По формуле (4) последовательно определяем $y_k$ , начиная с $y_N-1$
  Для задания $y_{N-1}$ запишем (4) для r = N - 2 и воспользуемся вторым уравнением (3)
  $y_{N-2} = \Theta_{N-2}y_{N-1} + \Psi_{N-2}$
  $\tilde{a_{N-1}}y_{N-2} + \tilde{b_{N-1}}y_{N-1} = -h^2\tilde{f_{N-1}}$ 
  Решая эти два уравнения совместно, для $y_{N-1}$ получаем
  ==(7)==$y_{N-1} = \frac{\tilde{a_{N-1}}\Psi_{N-2}+h^2\tilde{f_{N-1}}}{\tilde{b_{N-1}} + \tilde{a_{N-1}}\Theta_{N-2}}$ 
  Нахождение $y_k$ по формулам (4) и (7) - обратная прогонка
  ***Достаточное условие успешного применения метода прогонки***   (выполнение условий для коэффициентов системы (1)):
  $a_k \not = 0$, $c_k \not= 0$, $|b_k|\geq|a_k|+|c_k|$, k = 1,2,...,N-2,   $|\Theta_1|\leq1$,  $|\tilde{a_{N-1}}| < |\tilde{b_{N-1}}|$ 
  
  *Линейная зависимость от трудоемкости*
  Нелинейные краевые задачи аналогичными приемами сводятся к решению некоторой  нелинейной системы уравнений  
  
  
# №2 Методы коллокации и Галеркина для решения краевых задач
***В основе***: аппроксимация решения дифференциального уравнения конечной линейной комбинацией базисных функций
*Пример: линейная двухточечная краевая задача*
$\frac{d}{dt}(p(t)\frac{d}{dt}y(t)) + q(t)y(t) = f(t)$,   $t\in[0,1]$, краевые условия: $y(0)=y(1)=0$
Приближенное решение найдем в виде: $y(t) = \sum_{k=1}^nc_k\phi_k(t)$ 
$\phi_1(t), \phi_2(t)...\phi_n(t)$ - базисные функции, удовлетворяющие граничным условиям задачи: $\phi_k(0)=\phi_k(1) = 0$ 

#### Метод коллокации
на $[0,1]$ выберем n точек $t_1, t_2, ... t_n$. Потребуем, чтобы приближенное решение в этих точках удовлетворяло уравнению:
$\frac{d}{dt}(p(t)\frac{d}{dt}\sum_{k=1}^nc_k\phi_k(t))|_{t=t_m}$  +  $q(t_m)\sum_{k=1}^nc_k\phi_k(t_m) = f(t_m)$, m = 1...n
После дифференцирования и группировки слагаемых получим линейную систему алгебраических уравнений для нахождения коэффициентов $c_k$, являющихся компонентами вектора  **c** = $(c_1, c_2, ...c_n)^T$
**Ac** = **f**, $\sum_{k=1}^na_{mk}c_k = f(t_m)$, m = 1...n
$a_{mk} = p(t_m)\phi''_k(t_m) + p'(t_m)\phi'_k(t_m)+q(t_m)+\phi_k(t_m)$ 

#### Метод Галеркина
Коэффициенты $c_k$ приближенного решения выбираются таким образом, чтобы невязка приближенного решения $r(t)$
$r(t) = \frac{d}{dt}(p(t)\frac{d}{dt}y(t)) + q(t)y(t0 - f(t)$ была бы ортогональна всем базисным функциям $(r(t),\phi_m(t)) = 0$
Переписав скалярное произведение в соответствии с его определением в пространстве непрерывных функций 
$\int_0^1(\frac{d}{dt}(p(t)\frac{d}{dt}y(t))+q(t)y(t) - f(t))\phi_m(t)dt = 0$
подставив в интеграл искомый вид решения и поменяв местами суммирование, получаем также систему линейных алгебраических уравнений относительно $c_k$
**Ac** = **f**,  $\sum_{k=1}^n a_{mk}c_k = \int_0^1f(t)\phi_m(t)$,   m =1...n
$a_{mk}= \int_0^1(\frac{d}{dt}(p(t)\frac{d}{dt}\phi_k(t)) + q(t)\phi_k(t))\phi_m(t)dt$
Интегрируя по частям  первое слагаемое под знаком интеграла для $a_{mk}$:    $a_{mk} = -\int_0^1 p(t)\frac{d\phi_k(t)}{dt}\frac{d\phi_m(t)}{dt}dt$  +  $\int_0^1q(t)\phi_k(t)\phi_m(t)dt$ 
Такое представление коэффициентов $a_{mk}$ не требует, чтобы приближенное решение (и базисные функции обладали вторыми производными)

##### note: 1. Матрицы коэффициентов в обоих методах в общем случае являются заполненными. 2. Преимущество метода Галеркина пред методом коллокации - симметричная матрица(для данной задачи)

# №3 Примеры уравнений в частных производных. Метод сеток и метод прямых для их решения
#### Уравнения в частных производных описывают физические явления
1. Уравнение переноса: $\frac{\partial u}{\partial t} = -a\frac{\partial u}{\partial x}+f(t,x)$
2. Уравнение теплопроводности(диффузии), называемое уравнением параболического типа: $\frac{\partial u}{\partial t} = a(\frac{\partial^2 u}{\partial x^2}+\frac{\partial^2 u}{\partial y^2}+ \frac{\partial^2 u}{\partial z^2})$ 
3. Волновое уравнение, называемое уравнением гиперболического типа: $\frac{\partial^2 u}{\partial t^2} = a(\frac{\partial^2 u}{\partial x^2}+\frac{\partial^2 u}{\partial y^2}+ \frac{\partial^2 u}{\partial z^2})$ 
4. Уравнение потенциала(уравнения Пуассона, Лапласа), называемое уравнением эллиптического типа: $\frac{\partial^2 u}{\partial x^2}+\frac{\partial^2 u}{\partial y^2}+ \frac{\partial^2 u}{\partial z^2} = f(x,y,z)$ 
Для выделения одного решения необходимо задать начальные и/или краевые условия. 
- *условие Дирихле*, когда задается начальное распределение функции u(t,x,y,z) на границах области ее изменения 
- *условие Неймана*, когда определяется изменение функции u(t,x,y,z) на границе, а также их различные комбинации.
#### Метод сеток
$a\frac{\partial^2 u}{\partial x^2}+b\frac{\partial^2 u}{\partial y^2}+ c\frac{\partial u}{\partial x} + d\frac{\partial u}{\partial y}+eu = f(x,y)$ - линейная двумерная стационарная задача, решение u(x,y) зависит от двух пространственных независимых переменных; a,b,c,d,f - известные функции x и y. Область изменения $(x\in[A,B], y\in[C,D])$ -форма прямоугольника
Введем дискретизацию по обеим независимым переменным:
$x_k = x_0 + h_xk$, $y_i = y_0+h_yi$, k =0,1...N, i = 0,1,...M
$h_x = \frac{A-B}{N}$, $h_y = \frac{D - C}{M}$,  $x_0$ = A, $x_N$ = B, $y_0 = C$, $y_M = D$
(Пусть $u(x_k,y_i) = u_{ki}$, $a(x_k,y_i) = a_{ki}$ и тд)
Граничные условия: 
$u(A, y_i) = \phi_1(y_i)$, $u(B, y_i) = \phi_2(y_i)$, $u(x_k, C) = \phi_3(x_k)$, $u(x_k, D) = \phi_4(x_k)$, где $\phi_1,\phi_2,\phi_3,\phi_4$ - известные функции x и y
Запишем исходное равнение в точке $(x_k,y_i)$, приближенно аппроксимируя производные по формулам численного дифференцирования:
$\frac{\partial^2u}{\partial x^2}(x_k, y_i)\simeq\frac{u_{k+1,i} - 2u_{k,i} + u_{k-1,i}}{h^2_x}$, $\frac{\partial^2u}{\partial y^2}(x_k, y_i)\simeq\frac{u_{k,i+1} - 2u_{k,i} + u_{k,i-1}}{h^2_y}$, 
$\frac{\partial^u}{\partial x}(x_k, y_i)\simeq\frac{u_{k+1,i} - u_{k-1,i}}{2h_x}$, $\frac{\partial^u}{\partial y}(x_k, y_i)\simeq\frac{u_{k,i+1} - u_{k,i-1}}{2h_y}$ 
Количество неизвестных $u_k,i$  = количество уравнений = (N-1)x(M-1), когда k = 1,2...N-1, i = 1,2...M-1. Оставшиеся значения $u_k,i$ известны и отвечают границам прямоугольника
- Если область на плоскости имеет относительно произвольный вид, то уравнения можно записать только в тех "внутренних" точках $(x_k, y_i)$, которые имеют четырех соседей:  $(x_k-1, y_i)$, $(x_k+1, y_i)$, $(x_k, y_i-1)$, $(x_k, y_i+1)$    
- Для точек, расположенных внутри области, но не имеющих хотя бы 1 "соседа", реализуют *"снос граничных условий"*, задавая этим $u_k,i$ значения ближайших точек границы области.
-  Увеличение точности решения <- увеличение N и M <-> уменьшение $h_x$ и $h_y$. Одновременно уменьшается погрешность *"сноса граничных условий"*. Также можно использовать более точные формулы численного дифференцирования(редко)
 #### Метод прямых
 Дискретизация по всем независимым переменным, кроме одной.
 $\frac{\partial u(x,t)}{\partial t} = a(x,t)\frac{\partial^2 u(x,t)}{\partial x^2}$, $x\in[o,L]$ - одномерный случай уравнения теплопроводности для тонкого стержня длиной L
 Начальные и граничные условия:
 $u(0,t) = \phi_1(t)$,  $u(L,t) = \phi_2(t)$,  $u(x,0) = \phi_3(x)$
 $a(x,t), \phi_1(t), \phi_2(t), \phi_3(t)$ - известные функции
 Введем дискретизацию по x: $x_k = k\Delta x$, $\Delta x = L/N$, $x_0 = 0$; $x_N = L$ 
 Используем простейшую формулу численного дифференцирования для второй производной, получим систему дифференциальных уравнений относительной $u_k(t) = u(x_k,t)$:
 $\frac{du_k(t)}{dt} = \frac{a_k(t)}{(\Delta x)^2}(u_{k+1}(t) - 2u_k(t) + u_{k-1}(t))$;  k = 1,2,...N-1
При этом $u_0(t) = \phi_1(t)$,  $u_N(t) = \phi_2(t)$
$u_k(0) = \phi_3(x_k)$, k = 1, 2,...N-1 - равенства, определяющие начальные условия
- Уменьшение $\Delta x$ -> увеличение точности аппроксимации, но происходит увеличение размерности системы и она становится жесткой ...
# №4 Минимизация функции одной переменной. Методы половинного деления, "золотого сечения", последовательной параболической интерполяции. Программа FMIN, пример ее использования в задаче параметрической идентификации математической модели
***Безусловная задача минимизации*** - множество S совпадает со всем n-мерным пространством. 
В противном случае задача имеет ограничения.(совокупность нелинейных функций  $g^{(i)}$, удовлетворяющих $g^{(i)}(x^{(i)}...x^{(i)}\geq 0$, i = 1,2...p) и определяющих множества S
- Если f и $g^{(i)}$ линейны - задача линейного программирования, иначе - нелинейного программирования
f(x) определена на $[a,b]$, имеет единственное решение = минимуму f на $[a,b]$, причем для $x>x^*$ - функция строго возрастает, для $x<x^*$ - строго убывает, те ==унимодальная функция==, ее минимум может достигаться как внутри промежутка, так и на его краях.
Пусть $\varepsilon$ - требуемая точность определения $x^*$. Тогда задача сводится к сокращению промежутка неопределенности $[a,b]$ до $[\tilde{a}, \tilde{b}]$, так, чтобы $x^* \in [\tilde{a}, \tilde{b}]$ и $\tilde{b} - \tilde{a} < \varepsilon$ 
Если функция вычислена в некоторых точках $x_0$ и $x_1$ промежутка неопределенности, то возможны три варианта расположения минимума и сокращения промежутка неопределенности:
![[Pasted image 20250323194931.png]]
Значит, f необходимо вычислить минимум в двух точках промежутка, что бы он мог быть сокращен.
#### Метод половинного деления
На очередном шаге вычисляется функция в двух точках: 
$x_0 = \frac{a+b}{2} - \frac{\varepsilon}{2}$ и $x_1 = \frac{a+b}{2} + \frac{\varepsilon}{2}$ с точностью до $\frac{\varepsilon}{2}$ совпадающих с серединой отрезка $[a,b]$
Например: 
- $f(x_0) < f(x_1)$ промежуток сокращается практически в 2 раза процедура повторяется уже на $[a, x_1]$, $x_0$ отбрасывается, тк расположена слишком близко к правому концу промежутка $[a,x_1]$
#### Метод золотого сечения
на каждом шаге сокращает промежуток на 38,2% независимо от вида умодальной функции(аналогично методу бисекций)
![[Pasted image 20250323200101.png]]
Точки расположены симметрично относительно середины промежутка и делят промежуток в такой пропорции, чтобы эта пропорция повторялась на следующем шаге с промежутком меньшей длины. Будем считать, что исходный промежуток единичной длины (a=0, b=1). Расстояние от 0 до левой точки xлев обозначим за $\alpha$, тогда расстояние $x_{прав}$ до 1 = $\alpha$, расстояние между $x_{прав}$ и $x_{лев}$ = $1 - 2\alpha$ 
- Отбрасывается левая часть -> $[x_{лев},1]$
- Отбрасывается правая часть -> $[0,x_{прав}]$
Отношение левой части промежутка к длине всего промежутка должно сохраняться на всех шагах и условие "повторяемой ситуации" приобретает вид:
$\frac{\alpha}{1} = {a-2\alpha}{a-\alpha}$ или $\alpha^2 - 3\alpha + 1 = 0$ и $\alpha_{1,2} = \frac{3+_- \sqrt{5}}{2}$ 
Одно из значений $\alpha > 1$  и  может быть отброшено, а второе значение $\alpha = \frac{3 - \sqrt{5}}{2}$ = 0,382
#### Метод последовательной параболической интерполяции
На каждом шаге ориентируется на 3 точки: $x_{k-2}, x_{k-1}, x_k$, пот ним строится парабола(интерполяционный полином второй степени), вершина - точка минимума - определяет значение $x_{k+1}$, которое заменяет $x_{k+2}$
#### FMIN(A, B, F, EPS)
==A, B - интервал поиска
F - вычисляемая функция;
EPS - граница погрешности==
Сочетание методов последовательной параболической интерполяции(основной метод) и золотого сечения(временное переключение, если сходимость основного метода замедляется)
- Если f(x ) = 0, f'(x) $\ne$ 0, то для малых $\varepsilon$: $f(x+\varepsilon) = f(x) + \varepsilon f'(x) + \varepsilon^2\frac{f"(x)}{2}+ ... = f(x) + \varepsilon^2\frac{f"(x)}{2}$
-Изменение порядка $\varepsilon$ в x -> изменение порядка $\varepsilon^2$ в f(x) -> граница - квадратный корень из ошибки значения функции
***Пример использования - параметрическая идентификация математической модели*** 
Цель: определить параметр _p_ модели объекта, описываемой системой дифференциальных уравнений $\frac{dx}{dt} = f(t, x, p)$, чтобы результаты моделирования соответствовали экспериментальным данным.
*Функция минимизации*:  
_F(p) = Σ (xₘ(tᵢ) - xₚ(tᵢ))²_, где:
- _xₘ(tᵢ)_ — экспериментальные данные,
- _xₚ(tᵢ)_ — результаты моделирования.
*Алгоритм решения*:  
Используется программа _FMIN_ для минимизации _F(p)_. Последовательность вызова:  
_MAIN → FMIN → F(p) → RKF45 (решение ОДУ) → f(t, x, p)_.
*Особые случаи*:
1. *Несколько компонент вектора x*:  
    _F(p) = Σ Σ (xₘₖ(tᵢ) - xₚₖ(tᵢ))²_, где _S_ — число измеряемых компонент.
2. *Разная размерность компонент*:  
    Ввод весовых коэффициентов _qₖ_ или использование относительного критерия _F(p) = Σ Σ [(xₘₖ - xₚₖ)/xₘₖ]²_.

# №5 Минимизация функций многих переменных, связь с задачей решения систем нелинейных уравнений
f(x) = $f(x^{(1)}, ..., x^{(m)})$ - функция многих переменных
Если функция непрерывна вместе со своими частными производными, то задача минимизации может быть сведена к решению системы нелинейных уравнений
==(1)== $grad f(x) = (\frac{\partial f}{\partial x^{(1)}} , \frac{\partial f}{\partial x^{(2)}} ... , \frac{\partial f}{\partial x^{(m)}})^T$ = 0 задающих нулевое значение компонентам вектора градиента f(x). С другой стороны, пусть задана некоторая система нелинейных уравнений
==(2)== $\phi_k(x) = \phi(x^{(1)}, ..., x^{(m)})$ = 0,   k = 1, 2, ..., m 
 Вместо ее решения можно минимизировать некоторую функцию
 ==(3)== $f(x) = \sum_{k = 1}^m \phi_k^2(x)$
 Ее минимум равен 0 и достигается при тех же значениях x, которые удовлетворяют системе (2)(могут появиться посторонние локальные экстремумы)
 Между методами минимизации функции и методами решений нелинейных уравнений существует тесная связь -> типовой является ситуация: 
 Если имеется хорошее начальное приближение к точке минимума минимизируемой функции f(x) -> переходим к решению системы (1) (например, методом Ньютона с квадратичной скоростью сходимости)
 Решение нелинейных уравнений (2) в отсутствии хорошего начального приближения ->получаем его, используя первоначально методы минимизации применительно к функции (3)

$x^*$ - точка минимума f(**x**)
$x_n$ - n-е приближение к $x*$
***Поверхность уровня(линия уровня)*** - множество значений вектора x, удовлетворяющих уравнению $f(x) = c_n$, где $c_n$ = const
==(1)== $x_{n+1} = x_n + hv_n$, где $v_n$ - вектор направленный не по касательной к поверхности уровня в точке $x_n$. h + или - значение, при котором $f(x_{n+1]}) < f(x_n)$.
различные методы отличаются друг от друга выбором $v_n$ и h. При заданном $v_n$ значение h может вычисляться из условия минимума функции $\Psi(h) = f(x_n + hv_n)$ -> минимизация только $\Psi(h)$, причем целесообразно остановиться на h: $f(x_{n+1})<f(x_n)$, сменить вектор $v_n$ на $v_{n+1}$ и продолжить минимизацию в другом направлении.
#### Метод покоординатного спуска
- в качестве $v_n$ выбраны компоненты x
###### Обычный (циклический) покоординатный спуск
- Все компоненты $x^{(k)}$  назначены в строго определенном порядке
###### Случайный покоординатный спуск
- Очередной компонент носит случайный характер
###### Релаксационный покоординатный спуск
- На каждом шаге в качестве $v_n$ выбирается та компонента, в направлении которой f(x) убывает быстрее всего

# № 9 Комплексы параметров в задачах минимизации, методика их выявления. 
**Комплексы параметров в задачах минимизации, методика их выявления**  
**Комплексы параметров** — это группы взаимосвязанных параметров, которые нельзя определить однозначно по отдельности, так как их оптимальные значения зависят от комбинаций (например, произведение x(1)x(2)=6x(1)x(2)=6 в функции f(x)=(x(1)x(2)−6)2+πf(x)=(x(1)x(2)−6)2+π).

**Методика выявления комплексов:**

1. **Нахождение начального минимума**: Определяется точка x∗x∗, обеспечивающая минимум f(x∗)=f∗f(x∗)=f∗.
    
2. **Фиксация параметров**:
    
    - Один из параметров x(k)x(k) изменяется и фиксируется.
        
    - Проводится повторная минимизация по остальным параметрам.
        
3. **Анализ результатов**:
    
    - Если новый минимум f(x∗∗)≈f∗f(x∗∗)≈f∗, фиксированный параметр входит в комплекс.
        
    - Если f(x∗∗)f(x∗∗) значительно отличается от f∗f∗, параметр не входит в комплекс.
        
4. **Итерации**: Процедура повторяется для других параметров до выявления всех взаимосвязей.
    
5. **Снижение размерности**: На основе априорной информации вводятся связи между параметрами комплекса (например, фиксация одного из них).
