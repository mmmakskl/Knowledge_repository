![[Pasted image 20250509123644.png]] -> аппроксимация f: $Q_{n-1}(x) = c_1\varphi_1(1) + c_2\varphi_2(x)+ ... + c_n\varphi_n(x) = \sum_{k=1}^nc_k\varphi_k(x)$ (1)
коэффициенты $c_k$ определяются из условия минимума квадрата расстояния между $Q_{n-1}(x) , f(x)$: $\rho^2 = (Q_{N-1}(x)-f(x), Q_{n-1}(x)-f(x)) = \sum_{k=1}^nc_k\varphi_k(x)$ (2)
Необходимое условие экстремума: $\frac{\delta\rho^2(c_k)}{\delta c_k} = 0$, k =1,2,...n
приводит к системе линейных алгебраических уравнений, которая с ростом числа искомых коэффициентов становится катастрофически плохо обусловленной, более надежно сингулярное разложение матрицы. Попытка максимально удачно описать табличную функцию с помощью $Q_{n-1}(x)$ приводит к: 
(3) $Ac \approx f$; $c = (c_1, c_2, ..., c_n)^T$; $f =(f(x_1), f(x_2), ...f(x_m))^T$, где элементы прямоугольной m x n А определяются по формулам: $a_{ik} = \varphi(x_i)$, i = 1, 2,...,m; k = 1, 2,...n

Вектор невязки r = Ac - f. Минимизация его длины: (r,r) -> min (0) полностью совпадает с задачей минимизации $\rho^2$. Будем искать с, чтобы квадрат длины вектора невязки был бы минимален. Заменяя в (3) матрицу A ее сингулярным разложением $U\sum V^T$ и умножая на $U^T$ -> $\sum V^Tc \approx U^Tf$->
$\tilde c = V^Tc$; $\tilde f = U^Tf$; $c = V\tilde c$; $f = U\tilde f$ (4)
$\sum \tilde c \approx \tilde f$ (5) -> вектор невязки: $\tilde r = \sum \tilde c - \tilde f$ -> длина  осталась прежней
Решение (5)
###### 1 случай
1.  $m \ge n$ -> две подсистемы
$\tilde c_k \sigma_k \approx \tilde f_k$ k = 1,2,...,n(6)
$0 \approx \tilde f_k$ k = n+1,...m(7), сингулярные числа упорядочены по убыванию
m = n -> подсистемы (7) отсутствует. Минимум $\rho^2$ и условие (0) <- (6)  решается точно ($\sigma_k \ne 0$) -> $\tilde c_k = \frac{\tilde f_k}{\sigma_k}$ k =1 ,2,...n (8)
min($\rho^2$)<-(7) -> (r,r) = ($\tilde r, \tilde r$) = $\sum_{k=n+1}^m \tilde f_k^2$ (9) (и для m = n)
2. Ненулевые $\sigma_k$
Пусть $\sigma_k = 0$ -> (6) переходит в (7), увеличивая значение минимума $\rho^2$, которое определяется неоднозначно и остается неизменным при произвольном $\tilde c_n$ -> $c = V c = c_{opt} + \tilde c_nv_n$ $v_n$ - последний столбец матрицы V,  $c_{opt}$ - определяется однозначно, $\tilde c_n$ - произвольно
- $\tilde c_n = 0$ -> с и $c_n$ одинаковая длина -> с с минимальной длиной
- с близкий к $c^*$ -> $\tilde c_n$ из условия $(c - c^*, c-c^*) = (c_{opt} + \tilde c_n v_n - c^*, c_{opt} + \tilde c_nv_n - c^*)$ -> min. В частности $c^* = 0$ -> $\tilde c_n = 0$
3. несколько последних сингулярных чисел = 0
-> $c = Vc = c_{opt} + \sum_{k=n_1}^n \tilde c_k\tilde v_k$, $v_k$ - последние столбцы V, произвольно могут выбираться несколько последних коэффициентов $\tilde c_k$ 
Используем матрицы эффективного ранга.
- А плохо обусловлена -> высокая чувствительность к вариации исходных данных -> есть малые сингулярные числа -> соответствующие компоненты $\tilde c_n$ принимают большое значение. Вводится $\varepsilon$ - точность исходных данных или длина разрядной сетки/. сингулярное число < $\varepsilon$ = 0 -> уменьшение $cond(A) = \frac{\sigma_{max}}{\varepsilon}$ -> увеличение надежности решения и уменьшение по модулю коэффициентов $\tilde c_k$, но увеличивается значение вектора матрицы невязки
###### 2 случай
m < n -> все сингулярные числа не нулевые -> (7) отсутствует, (6) -> $\tilde c_k \sigma_k = \tilde f_k$ k =1,2,..m
Первые m значений выбираются из условия: $\\tilde c_k = \frac{\tilde f_k}{\sigma_k}$ k = 1,2,...m
-> $\rho^2 \ne 0$ и произвольный выбор остальных $\tilde c_k$
- $\tilde c_k = 0$ -> min c и $\tilde c$(но не обязательно)
$c = V \tilde c = c_{opt} + \sum_{k = m+1}^n \tilde c_k v_k$
- если некоторые $\sigma_k = 0$ -> (7) -> min $\rho^2$ -> увеличение свободно задаваемых  $\tilde c_k$ увеличивается на число нулевых $\sigma_k$
