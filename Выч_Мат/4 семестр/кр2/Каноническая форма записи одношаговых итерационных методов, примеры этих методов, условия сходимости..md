#### Каноническая форма записи
Итерационные методы дают возможность для системы Ax=b (1)построить последовательность векторов $x_0, x_1...x_n...$, пределом которой должно быть точное решение $x^* = lim_{n->\infty}x_n$(2)
На практике: до достижения желаемой точности: |$x^* - x_n$| < $\varepsilon$
Схема метода последовательных приближений:
1. Эквивалентными преобразованиями(сохраняют решение системы) привести систему к виду x = Cx +d (3)-> точное решение системы: $x^* = (E - C)^{-1}d$(4)
2. Вместо (3) будем решать систему разностный уравнений: $x_{n+1} = Cx_n + d$ (5) пошаговым методом
3. Решение имеет вид: $x_n  = C^nx_0 - c^n(E-C)^{-1}d=C^n(x_0 - x^*)$ (6)
4.  (6) - (4) -> $x_n - x^* = C^nx_0 - C^n(E-C)^{-1}d = C^n(x_0 - x^*)$ (7)
5. Все элементы матрицы должны стремиться к 0, чтобы обеспечить условие сходимости -> НИД: $|\lambda_k| < 1$ -> используем достаточное условие :$||C|| < 1$

# Каноническая форма одношагового итерационного метода

Любой одношаговый итерационный метод для системы $Ax = b$ можно записать в виде $B_{n+1},\frac{x_{n+1} - x_n}{\tau_{n+1}} + Ax_n = b$ где $x_n$ — текущее приближение, $x_{n+1}$ — следующее;  $B_{n+1}$ — матрица, задающая структуру метода;   $\tau_{n+1}$ — шаг (или параметр релаксации) на шаге $n+1$
По выбору $B_{n+1}$ и $\tau_{n+1}$ различают: **явные** ($B_{n+1} = E$) и **неявные** ($B_{n+1}\neq E$); **стационарные** ($B_{n+1}=\mathrm{const},,\tau_{n+1}=\mathrm{const}$) и **нестационарные** ($\tau_{n+1}$ и/или $B_{n+1}$ меняются)

Примеры:
1. Метод простой итерации
    - $B_{n+1}=E$, $\tau_{n+1}=\tau=\mathrm{const}$  Итерация: $x_{n+1} = (E - \tau A),x_n + \tau b$ Условие сходимости: $0 < \tau < \tfrac{2}{\lambda_{\max}(A)}$
2. Итерационный метод Ричардса
    $B_{n+1}=E$, но $\tau_{n+1}$ меняется от итерации к итерации Итерация:  $x_{n+1} = x_n + \tau_{n+1}(b - A,x_n)$ Оптимальный подбор $\tau_{n+1}$ (например, на основе полиномов Чебышева) ускоряет сходимость
3. Метод Якоби
	 Разбиение $A = D + L + U$, где $D$ — диагональная часть, $L$ — нижняя треугольная, $U$ — верхняя $B_{n+1}=D$, $\tau_{n+1}=1$  Итерация:  $x_{n+1} = D^{-1}(b - (L+U),x_n)$
4. Метод Гаусса–Зейделя
    $B_{n+1}=D + L$, $\tau_{n+1}=1$ Итерация: $x_{n+1} = -(D+L)^{-1}U,x_n + (D+L)^{-1}b$ При вычислении $x_{n+1}^{(k)}$ используются уже обновлённые $x_{n+1}^{(j)}$ для $j<k$
5. Метод верхней релаксации (SOR) $B_{n+1} = D + \omega L$, $\tau_{n+1}=\omega$, где $0 < \omega < 2$ При $\omega = 1$ метод совпадает с методом Гаусса–Зейделя
