# 1. Построение QR-разложения матрицы
QR-разложение матрица A - ее представление в виде **A = QR**, где Q - ортогональная R - верхняя треугольная матрица.
#### Преобразования Хайсхолдера
Исходная матрица A имеет размерность m x m.
1. $x_1$ = первому столбцу матрицы A: $x_1$ = $(a_{11}, a_{21},.., a_{m1})^T$
$v_1 = x_1 + ||x_1||e_1$ -> построим матрицу Хаусхолдера на основе вектора $H_1$. Векторы $x_1, v_1, e_1$ имеют размерность m, $H_1$ - размерность m x m.
Ортогональная матрица $U_1 = H_1$, умножим матрицу A слева на $U_1$.  Первый столбец получившейся матрицы приобретает вид первого столбца верхней треугольной матрицы (свойства 3 преобразования Хаусхолдера)![[Pasted image 20250509094734.png]]
2. Построим вектор $x_2$ размерности m-1, как второй столбец матрицы $U_1A$ без первого элемента, и вектор v2^
$x_2 = (a_{22}^*, a_{32}^*, a_{m2}^*)^T$ $v_2 = x_2 + ||x_2||e_1$, $e_1$ - столбец единичной матрицы E размерности m-1. Матрица Хаусхолдера H_2 на основе $v_2$ - (m-1) x (m-1). Ортогональная матрица $U_2$ размерностью m x m, первая строка и столбец которрой совпадают с E, а остальные элементы равны $H-2$: ![[Pasted image 20250509095358.png]]
Умножая $U_1A$ справа на $U_2$ обеспечиваем два столбца верхней треугольной матрицы ![[Pasted image 20250509095458.png]]

Данный процесс позволяет получить верхнюю треугольную матрицу R за m-1  шагов ![[Pasted image 20250509095614.png]]
Ортогональность матрицы Q следует из симметричности и ортогональности матрицы $U_k$

# 2. Построение QR-алгоритма для решения полной проблемы собственных значений и пути повышения его эффективности(сокращение числа итераций и уменьшение объема вычислений на каждом шаге)
Обозначим $A_0 = A$
На шаге k выполняется QR-разложение матрицы $A_k$. Затем матрицы $Q_k$ и $R_k$ перемножаются в обратном порядке для получения $A_{k+1}$. Матрицы $A_k, A_{k+1}$ - подобны, собственные значения в результате такого преобразования сохраняются 
(1) $A_k = Q_kR_k$, $A_{k+1} = R_kQ_k$, $A_{k+1} = Q_{k}^{-1}A_kQ_k = Q_k^T A_kQ_k$
1. Пусть первоначально собственные значения матрицы A различны. Тогда, с ростом числа шагов сумма модулей элементов $A_k$, расположенных ниже главной диагонали, убывает и в пределе $k->\infty$ стремится к нулю. Матрица $A_k$ в пределе становится верхней треугольной, а ее диагональные элементы стремятся к собственным значения исходной матрицы. 
2. Есть комплексно-сопряженные или кратные значения среди собственных значений A. -> $A_k$- блочной квазитреугольной![[Pasted image 20250509101037.png]], $A_{ii}$ - квадратные подматрицы(матричные клетки), $A_{ij} > 0$, для всех $i > j$. Собственные значения $\lambda_k$ исходной матрицы отпределяются собственными значениями всех диагональных клеток. 
- Вещественные $\lambda_k$ не являются квадратными, ->  диагональные клетки первого порядка 1x1. 
- Комплексно-сопряженной паре $\lambda{k,k+1}$ -> диагональная клетка 2x2
- $\lambda_k$ имеет кратность s -> соответствующую размерность sxs имеет диагональная клетка
Затруднения:
- Недостаточно быстрая сходимость
- Трудоемкие операции QR-разложения на каждом шаге и умножение матриц
Сокращение алгоритма:
- Уменьшение количества итераций -> повышение скорости сходимости(алгоритм со сдвигами)
- Снижение трудоемкости 1 шага (предварительное приведение матрицы к форме Хессенберга)
#### Алгоритм со сдвигами 
- Известно приближение $\tau_k$ к некоторому собственному значению A -> $A_k = \tau_kE = Q_kR_k$; $A_{k+1} = R_kQ_k + \tau_kE$
каждая итерация сохраняет собственные значения матрицы 
#### Предварительное привдение матрицы к форме Хессенберга
$A_0 = A$ (m x m)-> однократно приводится к форме Хессенберга(для снижения объема вычислений)
- Обычный вид матрицы -> операции + и x -> (-$m^3$)
- Хессенберга -> ($-m^2$)
- Последующие шаги алгоритма сохраняют форму Хессенберга  для $A_k$:
$A_0$ - имеет форму Хессенберга ![[Pasted image 20250509103023.png]]   -> $Q_o = A_0R^{-1}$ имеет такойже вид, в чем можно убедиться умножением![[Pasted image 20250509103134.png]]
Перемножая $Q_o, R_0$ в обратном порядке получаем $A_1$ сохраняет форму $A_0$![[Pasted image 20250509103250.png]]
- Уравновешивание( баллансировка) -> уменьшение норма A-> уменьшение относительной погрешности результатов
- Подобные преобразования осуществляюются и с ортаногальными матрицами
# 3. Использование преобразований Гивенса для приведения матрицы к форме Хессенберга
Преобразования Гивенса - преобразоания с матрицей (1)вращения(отличается от E 4 элементами, стоящими на пересечении двух строк и двухстолбцов k и j ): $t_{kk} = t{jj} = c$; $t_{jk = -t{kj} = s}$; $c^2 + s^2 = 1$
Перемножением можно убедится, что матрица ортагональна: $T^{-1}_{kj} = T^T_{kj}$; $T_{kj}^T T_{kj} = E$
(1) ![[Pasted image 20250509104036.png]]
$A_{(k)}$ - k-й столбец A, $A^{(k)}$ - k-я строка
Умножим A на $T_{kj}(B=AT_{kj})$ матрицы A и B отличаются 2 столбцами: $B_{(k)} = cA_{(k)} + sA_{(j)}$; $B_{(j)} = -sA_{(k)} + cA_{(j)}$ (2)
$T_{kj}^T$ умножим на B -> $G^{(j)} = -sB^{(k)} + cB^{(j)}$. Матрицы G и B отличаются 2 строками : $G^{(k)} = cB^{(k)} + sB^{(j)}$, $G^{(j)} = -sB^{(k)} + cB^{(j)}$ (3)
Т.е. в $G = T_{kj}^TAT_{kj}$по сравнию с A изменяется 2 строки и 2 столбца с номерами j и k. 
$g_{ps}$ - элементы G (1 < j < k), выберем c и s так, чтобы $g_{k,j-1} = 0$-> $g_{k,j-1} = cb_{k,j-1} + sb_{j,j-1} = ca_{k,j-1} + sa_{j,j-1}$ -> толбец с номером j-1 в матрицах B и A одинаковый
При $g_{k,j-1} = 0$ -> ![[Pasted image 20250509105248.png]]
Проводя последовательно подобные преобразования с матрицами $T_{32}, T_{42}, ..,T_{m2}$ -> первый столбец как в матрице Хессенберга
Желаемая форма 2 столбца достинается использованием матриц $T_{43}, T_{53}, ..., T_{m3}$ и тд.Выполнив суммарно $\frac{(m-2)(m-1)}{2}$ аналогичных преобразований, получаем матрицу в форме Хессеньерга. Последующее преобразование сохраняет ранее полученные нулевые элементы. 
Для достижения результата количество преобразований Гивенса > количества преобразований Хаусхолдера, но изменения сводияся к 2 столбцам и 2 строкам.

# 4. Сингулярное разложение матрицы. Связь сингулярных чисел с матрицами $A^TA$ и $AA^T$. Эффективный ранг матрицы. Построение сингулярного разложения, программа SVD
A - прямоугольная матрица размерностью m x m 
сингулярное разложение матрицы А с вещественными элементами называется ее представление в виде: $A = U\sum V^T$, $U x U^T = E_{m}$, $V x V^T = E_n$ (1), где U - ортогональная матрица m x m, V - ортогональная матрица n x n, $\sum$ - диагональная матрица размерностью m x n с элементами $\sigma_{kj} =0$ при $k \not = j$ и $\sigma_{kk} = \sigma_{k} \ge 0$ $E_m$ и $E_n$ - единичные матрицы, $\sigma_k$ - сингулярные числа, столбцы  U и V -левые и правые сингулярные векторы
#### Связь сингулярных чисел матрицами ..

Рассмотрим две симметричные матрицы $A^TA$, $AA^T$ размерностью m x m иn x n:  ![[Pasted image 20250509115149.png]]
Пусть $m \ge n$ , $a^TA$ подобна $\sum^t\sum$ и имеет такие же собственные значения, которые равны квадратам сингулярных чисел матрицы A.
Первые n собственных значений матрицы $AA^T$ также равны квадратам сингулярных чисел, а остальные (m-n) собственных значений являются нулевыми, т.е . сингулярные числа матрицы A - положительные квадратные корни из нулевых собственных значений матриц $A^TA$ и $AA^T$
Разложение (1) допускает неиндивидуальность построения, тк определение допускает любой порядок сингулярных чисел на диагонали матрицы $\sum$ и для кратных сингулярных чисел соответствующие столбцы U и V определены неоднозначно и последние (m-n) строк матрицы $\sum$ являются нулевыми и элементы последних (m-n) столбцов U могут выбираться произвольно, так как вклад в формирование матрицы A осуществляют лишь первые n столбцов U
#### Эффективный ранг матрицы
Ранг матрицы A(максимальное число ее линейно независимы столбцов) совпадает с рангом матрицы $\sum$, те с числом ненулевых сингулярных чисел. 
- $m \ge n$ ->  rank(A) = n - матрица полного ранга
- Иначе недостаточного ранга
- Эффективный ранг - количество сингулярных чисел, удовлетворяющих условию $\sigma_k > \varepsilon$, $\varepsilon$ - характеризует погрешность представления исходных данных
Число обусловленности матрицы  полного ранга: $cond = \frac{\sigma_{max}}{\sigma_min}$ (не совпадает с числом обусловленности в программе DCOMP)

#### SDV (NM, M, N, A, W, MATU, U, MATV, V, IERR, RV1)

M - число строк матриц Aи U
N - число столбцов A и порядок V
A - исходная прямоугольная матрица
MATU - логическая переменная (TRUE - U нужно вычислять, FALSE - не нужно)
MATV - логическая переменная (TRUE - V нужно вычислять, FALSE - не нужно)
W - содержит N сингулярных чисел матрицы A
U - содержит матрицу U
V - содержит матрицу V
IERR - 0 -> нормальный выход из программы, K  -> $\sigma_k$ не было определено после 30 итераций
RV1 - одномерный массив промежуточного хранения
