Псевдообратной матрицей Мура-Пенроуза называется матрица $X = A^+$, удовлетворяющая 4 условиям
1. AXA = A
2. XAX = X
3. AX - симметричная
4. XA - симметричная
Можно показать, что такая матрица  X существует и единственная, и для ее построения применяется сингулярное разложение.

С учетом этих равенств -> ![[Pasted image 20250509145132.png]]
а матрица AX и XA - симметрические. 
Для m < n аналогично.
A -> $a_{ij}$,  $A^+$  -> $A_{ij}^+$, U -> $u_{ij}$, V -> $v_{ij}$ - элементы
Тогда: $a_{ij} = \sum_{k = 1}^n \sigma_ku_{ik}v_{jk}$; $a_{ij}^+ = \sum_{\sigma_k \ne 0} \frac{v_{ik}u_{jk}}{\sigma_k}$
Эффективная псевдообратная матрица $A^+_{\varepsilon}$ -> уменьшение числа обусловленности -> повышение надежности результатов
![[Pasted image 20250509145757.png]] ->$a_{ij}^+(\varepsilon) = \sum_{\sigma_k > \varepsilon} \frac{v_{ik}u_{jk}}{\sigma_k}$
Эффективная псевдообратная матрица удовлетворяет трем последним условиям, а первое выполняется с точностью до $\varepsilon$: $||AXA -A|| \le \varepsilon$
Для ненулевого значения $\varepsilon$ X может оказаться неединственной, удовлетворяющая этим 4 условиям. Но матрица с такими элементами дополнительно обладает наименьшей нормой
