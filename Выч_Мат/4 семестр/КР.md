**Билет: Комплексы параметров в задачах минимизации, методика их выявления**
**1. Определение комплексов параметров**  
Комплексы параметров — это группы взаимосвязанных переменных, которые не могут быть однозначно определены по отдельности. Минимум функции достигается при определенных комбинациях этих параметров, но их индивидуальные значения остаются неоднозначными.  
**2. Пример функции с комплексами**  
Для функции:  ${ f(x^{(1)}, x^{(2)}) = \left( x^{(1)} x^{(2)} - 6 \right)^2 + \pi }$  
минимальное значение ${ f = \pi }$ достигается при ${ x^{(1)} x^{(2)} = 6 }$. Однако отдельные значения ${ x^{(1)} }$ и ${ x^{(2)} }$ могут быть любыми, удовлетворяющими этому условию, что делает их комплексами.  
**3. Методика выявления комплексов**  
- **Шаг 1**: Находят точку минимума ${ x^* }$, где ${ f(x^*) = f^* }$.  
- **Шаг 2**: Изменяют один из параметров ${ x^{(k)} }$ на небольшую величину и фиксируют его.  
- **Шаг 3**: Проводят повторную минимизацию ${ f(x) }$ по оставшимся параметрам.  
- **Шаг 4**: Если в новой точке ${ x^{**} }$ значение ${ f(x^{**}) \approx f^* }$, то измененный параметр входит в комплексы.  
- **Шаг 5**: Процедуру повторяют для других параметров, чтобы определить все входящие в комплексы.  
**4. Действия после выявления**  
- **Понижение размерности**: Число независимо варьируемых параметров уменьшают на единицу (например, фиксацией одного из них или введением связи между ними).  
- **Использование априорной информации**: Включают дополнительные данные о параметрах для однозначного определения комплексов.  
**5. Автоматизация**  
Методика может быть автоматизирована, но требует диалога с исследователем для ввода априорной информации.  

**Билет: Барьерные и штрафные функции в задачах условной минимизации**  
### **1. Общая идея**  
Для решения задач условной минимизации (с ограничениями) методы барьерных и штрафных функций преобразуют исходную задачу в последовательность задач **безусловной** минимизации.  
### **2. Метод барьерных функций**  
- **Цель**: Удержание точки минимума **внутри** допустимой области.  
- **Функция**: ${  F(x, \alpha) = f(x) + T(x, \alpha),}$  
  где ${ T(x, \alpha) }$ — барьерная функция, резко возрастающая при приближении к границе допустимой области.  
- **Примеры барьерных функций**:  
  1. ${ T(x, \alpha) = \alpha \sum_{k=1}^{s} \frac{1}{c_k(x)} }$ (обратная функция),  
  2. ${ T(x, \alpha) = -\alpha \sum_{k=1}^{s} \ln c_k(x) }$ (логарифмический барьер).  
- **Процесс**:  
  - Начальное приближение ${ x_0 }$ выбирается **внутри** области (где ${ c_k(x) > 0 }$).  
  - Параметр ${ \alpha }$ последовательно уменьшается (например, ${ \alpha = 10^{-m} }$).  
  - При уменьшении ${ \alpha }$ барьер ослабевает, и точка минимума приближается к границе области.  
### **3. Метод штрафных функций**  
- **Цель**: Приближение к минимуму **извне** допустимой области.  
- **Функция**:  
  ${  F(x, \alpha) = f(x) + T(x, \alpha),}$  
  где ${ T(x, \alpha) }$ — штрафная функция, возрастающая при нарушении ограничений.  
- **Пример штрафной функции**:  
  ${  T(x, \alpha) = \frac{1}{\alpha} \sum_{k=1}^{s} \left[ \min(0, c_k(x)) \right]^2.}$  
- **Процесс**:  
  - Начальное приближение ${ x_0 }$ выбирается **вне** области (где ${ c_k(x) < 0 }$).  
  - Параметр ${ \alpha }$ последовательно уменьшается.  
  - При уменьшении ${ \alpha }$ штраф усиливается, "толкая" точку минимума к границе области.  

---

### **4. Сравнение методов**  
| **Критерий**          | **Барьерные функции**                        | **Штрафные функции**           |     |
| --------------------- | -------------------------------------------- | ------------------------------ | --- |
| **Начальная точка**   | Внутри допустимой области                    | Вне допустимой области         |     |
| **Поведение функции** | Блокирует выход за границу                   | Штрафует нарушение ограничений |     |
| **Сложность**         | Требует строгого соблюдения ${ c_k(x) > 0 }$ | Допускает начальные нарушения  |     |

---

### **5. Особенности**  
- **Барьерные функции**:  
  - Эффективны для задач с **явными границами**.  
  - Риск численной нестабильности при приближении к границе.  
- **Штрафные функции**:  
  - Подходят для задач с **нестрогими ограничениями**.  
  - Могут создавать "овражность" функции ${ F(x) }$.  

---

### **6. Альтернативные подходы**  
Для простых ограничений (например, ${ a \leq x \leq b }$) применяют **замену переменных**:  
- ${ x = a + \frac{b - a}{2} (1 + \sin q) }$,  
- ${ x = \sqrt{q} }$ (для ${ x \geq 0 }$).  
Это позволяет свести задачу к безусловной минимизации.  

---

**Итог**: Оба метода позволяют решать задачи с ограничениями, но выбор зависит от типа ограничений и начальных условий.




:

\[
\Delta A\,u_k \;+\; A\,\Delta u_k
\;=\;
\Delta\lambda_k\,u_k \;+\;\lambda_k\,\Delta u_k.
\tag{4}
\]

Оценивая изменение собственного значения «сверху», получаем

\[
\bigl|\Delta\lambda_k\bigr|
\;\le\;
\frac{\|\Delta A\|\;\|v_k\|\;\|u_k\|}{\bigl|v_k^T u_k\bigr|}
\;=\;
C_k\,\|\Delta A\|,
\quad
C_k = \frac{\|v_k\|\;\|u_k\|}{\bigl|v_k^T u_k\bigr|}=
\frac{1}{\cos\varphi_k}.
\tag{7}
\]

Здесь
- \(v_k\) — соответствующий \(k\)-й левый собственный вектор (\(A^T v_k = \lambda_k v_k\)),
- \(C_k\) — коэффициент перекоса,
- \(\varphi_k\) — угол между \(v_k\) и \(u_k\).

Для оценки погрешности собственного вектора рассмотрим случай \(j\neq k\). Из уравнения (5) и ортогональности \(\{v_j\}\) получаем для компонент разложения \(\Delta u_k\) по базису \(\{u_j\}\):

\[
\frac{\|\Delta u_k\|}{\|u_k\|}
\;\le\;
\|\Delta A\|\;
\sum_{j\neq k}
\frac{C_j}{\bigl|\lambda_k-\lambda_j\bigr|}.
\tag{11}
\]

Неравенства (7) и (11) дают следующие выводы:

- Чтобы \(\Delta\lambda_k\) оставалось соизмеримым с \(\|\Delta A\|\), коэффициент перекоса \(C_k\) не должен быть слишком велик.  
- В случае симметрической матрицы \(A\) имеем \(u_k=v_k\), \(C_k=1\), и тогда из (7) следует простое неравенство
  \[
    \bigl|\Delta\lambda_k\bigr| \le \|\Delta A\|.
  \]
- Погрешность собственного вектора тем больше, чем ближе к \(\lambda_k\) находятся другие собственные значения \(\lambda_j\) (чем меньше \(|\lambda_k-\lambda_j|\)).
