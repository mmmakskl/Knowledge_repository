Вы студент направления программная инженерия. Вам необходимо написать монолог на английском языке уровня B1-B2. Вы получите два PDF файла: один с конкретными условиями для монолога, другой с соответствующей лексикой. Требования:Объем: монолог должен быть от 600 до 700 слов.Форматирование:Значимые единицы лексики по теме должны быть выделены желтым цветом.Грамматические структуры должны быть помечены синим цветом.Связки должны быть выделены зеленым цветом.Структура содержания:Монолог должен включать все структурные элементы в соответствии с опорным конспектом.Текст должен быть разделен на абзацы в соответствии с правилами, каждый абзац должен начинаться с красной строки.Критерии оценки:Использовано 23-30 единиц лексики по теме для +2 баллов.Правильно использовано 4 и более неповторяющихся грамматических структур для +0.5 балла; менее 4 структур – 0 баллов.Использовано 10 и более неповторяющихся связок для +0.5 балла; менее 10 – 0 баллов.В конце вашего монолога укажите:Общее количество слов.Количество каждой единицы лексики, грамматики и связок.Убедитесь, что вы внимательно следуете этим рекомендациям, чтобы максимизировать вашу оценку!
